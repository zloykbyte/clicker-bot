# Telegram-кликер

Бот на Python + aiogram 3. Кнопка «Клик», улучшение силы клика за очки, топ игроков. Данные хранятся в SQLite.

## Mini App

Игра лежит в `docs/index.html` и публикуется через GitHub Pages (Settings → Pages → Deploy from a branch → `main` → `/docs`). Адрес по умолчанию: `https://zloykbyte.github.io/clicker-bot/`, его можно заменить переменной `WEBAPP_URL` в `.env`.

Прогресс игрока хранится в облаке Telegram (CloudStorage) и в браузере. Для рейтинга и учёта посещений Mini App отправляет боту сводку (монеты, сила клика, заработок) на его API; подпись Telegram (`initData`) проверяется на сервере. Это не защита от накрутки: значения приходят с устройства игрока.

## Запуск на Windows в один клик

1. Установите Python с [python.org](https://www.python.org/downloads/) (отметьте «Add Python to PATH»).
2. Скачайте репозиторий (Code → Download ZIP) и распакуйте архив (правая кнопка → «Извлечь всё»).
3. Дважды кликните по `start.bat`. При первом запуске он спросит токен, создаст `.env`, установит пакеты и запустит бота.

Остановить бота: `Ctrl+C` или закрыть окно.

## Запуск вручную

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env             # Windows: copy .env.example .env
# впишите токен от @BotFather в .env
python bot.py
```

Токен хранится только в `.env`. Файл добавлен в `.gitignore`, в репозиторий он не попадёт.

## Команды

- `/start` открывает игру
- `/top` кнопка на Mini App с рейтингом: монеты, сила клика, общий заработок; топ-3 / топ-10 / топ-100 и кнопка «Обновить»
- `/admin` админка обычными сообщениями (только для `ADMIN_ID`): статистика, топы, игроки (поиск по Telegram ID), активность, обновить, закрыть

### Рейтинг и админка: нужен публичный адрес API

Бот поднимает маленький HTTP API (порт `API_PORT`, по умолчанию 8080), а Mini App на GitHub Pages ходит к нему по https. Если бот запущен у вас на компьютере, откройте туннель, например `cloudflared tunnel --url http://localhost:8080`, и впишите выданный адрес в `.env`: `API_PUBLIC_URL=https://....trycloudflare.com`. На хостинге укажите свой домен. Адрес передаётся в Mini App через ссылку кнопок бота, менять `docs/index.html` не нужно. Без `API_PUBLIC_URL` игра работает как раньше, но рейтинг пуст и посещения не считаются.

Посещение засчитывается при входе в игру, один день — одно, по часовому поясу `TZ_NAME`. «Активный» игрок: заходил в 3 разных дня из последних 7.

## База данных

Старый классик-кликер (`/classic`) удалён из кода. Его таблица `users` в файле базы не тронута и не используется. Рейтинг и статистика берутся из новых таблиц `players` и `visits`.

## Деплой

Подойдёт любой хостинг с постоянным процессом (Railway, Render, VPS). Команда запуска: `python bot.py`, переменная окружения: `BOT_TOKEN`. Если нужно, чтобы база переживала перезапуски, смонтируйте диск и укажите путь в `DB_PATH`.
