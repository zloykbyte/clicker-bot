# Telegram-кликер

Бот на Python + aiogram 3. Кнопка «Клик», улучшение силы клика за очки, топ игроков. Данные хранятся в Postgres (внешняя база — так бот может работать и как обычный процесс с long-polling, и как serverless-функции на Vercel).

## Mini App

Игра лежит в `docs/index.html` и публикуется через GitHub Pages (Settings → Pages → Deploy from a branch → `main` → `/docs`). Адрес по умолчанию: `https://zloykbyte.github.io/clicker-bot/`, его можно заменить переменной `WEBAPP_URL` в `.env`.

Прогресс игрока хранится в облаке Telegram (CloudStorage) и в браузере. Для рейтинга и учёта посещений Mini App отправляет боту сводку (монеты, сила клика, заработок) на его API; подпись Telegram (`initData`) проверяется на сервере. Это не защита от накрутки: значения приходят с устройства игрока.

## Запуск на Windows в один клик

1. Установите Python с [python.org](https://www.python.org/downloads/) (отметьте «Add Python to PATH»).
2. Скачайте репозиторий (Code → Download ZIP) и распакуйте архив (правая кнопка → «Извлечь всё»).
3. Дважды кликните по `start.bat`. При первом запуске он спросит токен и строку подключения к Postgres (подойдёт бесплатная база на [neon.tech](https://neon.tech) или [supabase.com](https://supabase.com)), создаст `.env`, установит пакеты и запустит бота.

Остановить бота: `Ctrl+C` или закрыть окно.

## Запуск вручную

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env             # Windows: copy .env.example .env
# впишите токен от @BotFather и строку подключения к Postgres (DATABASE_URL) в .env
python bot.py
```

Нужен доступ к Postgres — локальный (`docker run -p 5432:5432 -e POSTGRES_PASSWORD=pass postgres`) или любой облачный (подойдёт то же, что и для Vercel — см. ниже). Таблицы создаются автоматически при первом запуске.

Токен и строка подключения хранятся только в `.env`. Файл добавлен в `.gitignore`, в репозиторий он не попадёт.

## Команды

- `/start` открывает игру
- `/top` кнопка на Mini App с рейтингом: монеты, сила клика, общий заработок; топ-3 / топ-10 / топ-100 и кнопка «Обновить»
- `/admin` админка обычными сообщениями (только для `ADMIN_ID`): статистика, топы, игроки (поиск по Telegram ID, выдача/списание монет, силы тапа и энергии), активность, обновить, закрыть

### Рейтинг и админка при локальном запуске/своём хостинге

(На Vercel всё это настраивается иначе — см. «Деплой на Vercel» ниже.)

Бот поднимает маленький HTTP API (порт `API_PORT`, по умолчанию 8080), а Mini App на GitHub Pages ходит к нему по https. Если бот запущен у вас на компьютере, откройте туннель, например `cloudflared tunnel --url http://localhost:8080`, и впишите выданный адрес в `.env`: `API_PUBLIC_URL=https://....trycloudflare.com`. На хостинге укажите свой домен. Адрес передаётся в Mini App через ссылку кнопок бота, менять `docs/index.html` не нужно. Без `API_PUBLIC_URL` игра работает как раньше, но рейтинг пуст и посещения не считаются.

Посещение засчитывается при входе в игру, один день — одно, по часовому поясу `TZ_NAME` (по умолчанию `Europe/Moscow`, МСК). «Активный» игрок: заходил в 3 разных дня из последних 7. Администратор (`ADMIN_ID`) не попадает в рейтинги `/top` и в топы `/admin`.

### Выдача/списание ресурсов из админки

В разделе «Игроки» после поиска по Telegram ID появляются кнопки «💰 Монеты», «👆 Сила тапа», «⚡ Энергия» — нажмите нужную и отправьте число (отрицательное — чтобы списать). Изменение копится на сервере и применяется в игре у игрока при следующей синхронизации (обычно в течение 30 секунд или сразу при следующем заходе), после чего игрок увидит уведомление в игре.

## База данных

Старый классик-кликер (`/classic`) удалён из кода. Его таблица `users` в файле базы не тронута и не используется. Рейтинг и статистика берутся из новых таблиц `players` и `visits`.

## Деплой на Vercel

На Vercel бот работает иначе, чем при локальном запуске: вместо long-polling (`python bot.py`
с бесконечным циклом) Telegram сам шлёт апдейты на вебхук, а API — это отдельные serverless-функции
в `api/*.py`. Вся игровая/админская логика (`bot.py`) при этом не дублируется — функции в `api/`
просто импортируют её. Mini App (`docs/index.html`) публикуется тем же проектом как статика.

### 1. База данных

Нужен внешний Postgres — у Vercel-функций нет локальных файлов между вызовами, поэтому SQLite
не подходит. Проще всего подключить интеграцию **Vercel Postgres** (Storage → Create Database →
Postgres) прямо в проекте — она сама пропишет переменную `POSTGRES_URL`, и бот подхватит её
без дополнительной настройки. Подойдёт и любой другой Postgres (Neon, Supabase и т.п.) — тогда
впишите его строку подключения в `DATABASE_URL`. Таблицы `players`/`visits` создаются автоматически
при первом обращении.

### 2. Переменные окружения проекта (Project Settings → Environment Variables)

| Переменная | Значение |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |
| `ADMIN_ID` | ваш Telegram ID (для `/admin`) |
| `API_PUBLIC_URL` | адрес деплоя, например `https://my-project.vercel.app` (без слэша на конце) |
| `WEBHOOK_SECRET` | произвольная строка — секрет для проверки вебхука (рекомендуется) |
| `WEBAPP_URL` | если Mini App публикуется тем же проектом на Vercel — впишите тот же `https://my-project.vercel.app`; если оставляете её на GitHub Pages — не трогайте (адрес по умолчанию уже на неё указывает) |
| `TZ_NAME` | по желанию, по умолчанию `Europe/Moscow` |
| `POSTGRES_URL` / `DATABASE_URL` | подставится само при подключении интеграции Vercel Postgres, либо впишите свою |

### 3. Деплой

Через Vercel CLI (`npm i -g vercel`, затем `vercel` из корня репозитория) либо подключив репозиторий
на vercel.com (Add New → Project). `vercel.json` уже настроен: `docs/` отдаётся как статика
(Mini App окажется на `https://my-project.vercel.app/`), а `api/*.py` станут функциями
`/api/health`, `/api/sync`, `/api/top`, `/api/webhook`.

### 4. Регистрация вебхука и меню бота

После первого успешного деплоя — один раз локально:

```bash
pip install -r requirements.txt
cp .env.example .env   # впишите BOT_TOKEN, API_PUBLIC_URL (адрес деплоя) и WEBHOOK_SECRET —
                        # те же значения, что и в переменных окружения на Vercel
python scripts/vercel_setup.py
```

Скрипт поставит вебхук на `<API_PUBLIC_URL>/api/webhook` и настроит кнопку «Играть» + команды бота.
Дальше бот работает полностью на Vercel — команда `python bot.py` для этого не нужна
(она остаётся как локальный/self-host вариант с long-polling, см. разделы выше).

### Ограничения serverless-режима

- Троттлинг синхронизации (не чаще раза в 3 сек) держится в памяти функции и сбрасывается при
  «холодном» старте — не страшно, просто иногда будет на один лишний запрос больше; данные это
  не теряет, они всё равно пишутся в Postgres.
- Каждый вызов функции — отдельный короткий процесс; пул соединений к Postgres переиспользуется,
  пока функция «тёплая», и переоткрывается заново при холодном старте (это нормально для Postgres).
